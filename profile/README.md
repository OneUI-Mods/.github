# OneUI Mods

Samsung Galaxy / One UIを使いやすくする、非公式のアプリ・モジュール集です。

## アプリ

| アプリ | 内容 |
| --- | --- |
| [OneUI Mods Manager](https://github.com/OneUI-Mods/OneUIModsManager) | アプリ一覧・GitHub Releaseの更新確認・実験版チャンネルの切り替え |
| [Dark App Tools](https://github.com/OneUI-Mods/DarkAppTools) | セサミ・povoのダークモード |
| [Galaxy Adaptive Bar](https://github.com/OneUI-Mods/galaxy-adaptive-statusbar) | 背景に応じたステータスバーの配色とアニメーション |
| [Galaxy Capture Tools](https://github.com/OneUI-Mods/GalaxyCaptureTools) | 画面録画・スクリーンショットの機能拡張 |
| [One UI Home Tweaks](https://github.com/OneUI-Mods/OneUIHomeTweaks) | ホーム・アプリ履歴・クイックパネルのカスタマイズ |
| [Galaxy Camera Tools](https://github.com/OneUI-Mods/GalaxyCameraTools) | Samsung Camera・Camera Assistant・Expert RAWの拡張 |
| [TailADB](https://github.com/OneUI-Mods/tail-adb) | Tailscale経由のADB接続 |
| [Galaxy Reload](https://github.com/OneUI-Mods/galaxy-reload) | SystemUIの再読み込み |
| [Galaxy Update Guard](https://github.com/OneUI-Mods/galaxy-update-guard) | GalaxyのOS更新を停止・復元 |
| [Galaxy Service Panel](https://github.com/OneUI-Mods/galaxy-service-panel) | Service Modeの表示を整理 |
| [SleepStore](https://github.com/OneUI-Mods/SleepStore) | ディープスリープ中のアプリの更新を支援 |
| [SIM Pilot](https://github.com/OneUI-Mods/sim-pilot) | デュアルSIMの通信切り替えを支援 |
| [Galaxy Shutter Mute Manager](https://github.com/OneUI-Mods/galaxy-shutter-mute-manager) | シャッター音の設定を管理 |
| [Galaxy Shutter Mute](https://github.com/OneUI-Mods/galaxy-shutter-mute) | シャッター音のカスタマイズ |

## 入手・対応環境

配布APKは各リポジトリのReleasesに掲載します。対応する端末・Android / One UIのバージョン、root・Vector・Shizukuなどの要件は、各アプリのREADMEとリリース説明を確認してください。対応範囲はアプリごとに異なります。

すべてのリポジトリをpublicで管理します。配布APKはreleaseビルドと署名を検証し、ライセンスは各リポジトリで案内します。

Samsungとは無関係の非公式プロジェクトです。
